架构与技术栈

一套按业务域拆分的分布式微服务架构，支撑渠道订货、履约、结算与客户经营的全链路交易。流量入口、服务治理、中间件与数据层逐层解耦，每一层都可以独立演进。

  • 云原生微服务
  • 按业务域拆分
  • Java 17 · Spring Boot 3
  • Nacos · RocketMQ · XXL-Job
01

架构全景

以终端访问为起点，向下串联流量入口、服务注册与治理、中间件与数据存储，再到持续交付。四层之间只通过标准接口协作，任一层的变更不会牵动其余各层。

02

微服务与 BFF

业务能力按领域拆成独立服务，每个服务可单独部署与扩容。面向不同终端的差异由 BFF 层吸收，业务服务不需要为每个端写一套接口。

01

BFF 双端接入

bff-web-base bff-manager-base Mobile PC Supplier Platform

Web 管理端与管理后台各有专属 BFF，再加上移动端、PC 端、供应商端与平台端的接入层，终端差异在这里收敛。

02

业务域拆分

Product Payment Order Marketing Membership Accounting System enablement Product search

商品、支付、订单、营销、会员、账务、系统赋能与商品搜索各自成为独立服务，按领域独立演进。

03

公共服务沉淀

service-common Config center Messaging & notification Automated deployment

公共能力统一收在 service-common，配合配置中心、消息通知与自动化部署，避免各业务域重复建设。

03

中间件与数据层

选型不做堆砌：每一件中间件都对应一个明确的工程问题，而不是"别人都在用"。

组件 在本平台承担的工程问题
NacosRegistry & Config 服务注册发现与配置管理，多环境命名空间隔离，配置在线热更新，无需重启服务。
MySQLRelational Storage 业务数据落库：按业务域隔离，统一审计字段与逻辑删除，资金与库存类表以乐观锁版本控制。
RedisCache & Concurrency 缓存与并发控制：热点数据缓存提升读性能，分布式锁守护库存与订单临界区，幂等键防重复提交。
ElasticsearchSearch Engine 商品全文检索：五类词库与字段级权重，多维聚合筛选，本地消息表异步同步，零停机索引重建。
RocketMQMessaging 异步消息：领域事件异步分发、削峰填谷，消费侧幂等，失败自动重试进入死信队列兜底。
XXL-JobScheduling 分布式调度：订单自动取消与收货、资金对账、资质预警扫描统一编排，支持失败重试与任务分片。
